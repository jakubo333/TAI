Plan Projektu: Baza Filmów – Zespół Agentów AI

1. Cel i Założenia Projektu

Celem zadania jest stworzenie prostej aplikacji internetowej, która umożliwia przeglądanie katalogu filmów, sprawdzanie informacji o aktorach oraz czytanie i dodawanie recenzji. Aplikacja jest tworzona przez zespół wyspecjalizowanych agentów AI, a docelowym rezultatem jest w pełni zintegrowany system wraz z kompleksową dokumentacją procesu deweloperskiego.

Stos technologiczny: PHP (backend), MySQL (relacyjna baza danych), HTML i CSS (interfejs użytkownika).

3. Harmonogram i Etapy Realizacji (Workflow)

Proces realizacji projektu opiera się na czterech głównych etapach:

  1. Etap I - Planowanie (Claude):
    • Ustalenie funkcjonalności: katalog filmów, wyszukiwarka, baza aktorów, recenzje z oceną 1-10.
    • Definicja modelu przepływu danych: Użytkownik → Frontend → PHP → MySQL.
    • Wygenerowanie specyfikacji i zarysu architektury.
  2. Etap II - Implementacja Równoległa (ChatGPT, Gemini, Mistral):
    • Baza Danych: Utworzenie tabel filmy, aktorzy, obsada (klucz główny jako para film_id, aktor_id), recenzje. Zasilenie bazy dużą paczką początkowych danych (V4).
    • Backend: Napisanie skryptów pobierających dane i zabezpieczenie wejść przed atakami SQL Injection.
    • Frontend: Zbudowanie widoków szczegółów, list filmów i formularzy.
  3. Etap III - Integracja i Testowanie (Llama):
    • Połączenie modułów (PHP renderujące HTML z danymi z MySQL).
    • Przeprowadzenie planu testów: weryfikacja ładowania strony, poprawności szczegółów filmu, przypisań aktorów, zapisu recenzji, walidacji pustych pól oraz niepoprawnych ocen.
  4. Etap IV - Dokumentacja (Cały Zespół):
    • Zapisanie podsumowań sesji w katalogu Sessions/ dla każdego z agentów.
    • Sporządzenie raportu końcowego Docs/Final-Report.md oraz raportu z podziału ról Docs/Agents-Roles.md.
    • Opracowanie instrukcji instalacji w pliku README.md.

4. Architektura i Przepływ Użytkownika

Aplikacja została zaprojektowana tak, aby realizować płynny przepływ akcji:

  • Użytkownik wchodzi na stronę główną, gdzie przegląda siatkę filmów pobraną z bazy MySQL lub używa wyszukiwarki.
  • Po kliknięciu w konkretny tytuł przechodzi do podstrony szczegółów (obsługiwanej przez backend PHP), gdzie widzi opis, obsadę oraz recenzje.
  • Użytkownik może zostawić własną recenzję wypełniając formularz. Backend weryfikuje dane (wymaga podania oceny w zakresie 1-10) i używa zapytań przygotowanych (PDO) w celu trwałego, bezpiecznego zapisu opinii w bazie danych.
  • Na podobnej zasadzie, kliknięcie nazwiska aktora otwiera jego profil z pełną filmografią realizowaną przez odpowiednie złączenie tabel.
